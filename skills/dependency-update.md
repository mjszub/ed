# Dependency Upgrade Skill

## Cel

Bezpieczna aktualizacja zależności.

## Proces

1. Sprawdź aktualną wersję.
2. Przeanalizuj zmiany.
3. Sprawdź breaking changes.
4. Aktualizuj minimalny zakres.
5. Uruchom właściwe testy.

## Zasady

- Nie aktualizuj wielu niezależnych rzeczy naraz.
- Dokumentuj ryzyka.
- Unikaj zmian pobocznych.
