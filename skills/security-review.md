# Security Review Skill

## Cel

Ocena bezpieczeństwa zmian.

## Sprawdź

- walidację danych,
- uprawnienia,
- sekrety,
- logowanie,
- zależności,
- wycieki informacji.

## Proces

1. Znajdź ryzyka.
2. Oceń wpływ.
3. Zaproponuj poprawki.
4. Zweryfikuj.

## Zasada

Nie wprowadzaj zmian bez wskazania konkretnego ryzyka.
