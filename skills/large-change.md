# Large Change Skill

## Cel

Prowadzenie dużych zmian.

## Kiedy używać

- migracje,
- duże funkcje,
- zmiany architektury,
- wiele modułów.

## Proces

1. Zmapuj aktualny system.
2. Znajdź zależności.
3. Przygotuj plan etapów.
4. Określ ryzyka.
5. Wykonuj jeden etap.
6. Zweryfikuj wynik.

## Punkty zatrzymania

Zatrzymaj się, gdy:

- pojawia się nieznana zależność,
- zakres rośnie,
- potrzebna jest decyzja architektoniczna.
