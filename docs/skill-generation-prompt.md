Stwórz skill dla agenta programistycznego.

Skill ma być krótką instrukcją operacyjną, a nie dokumentacją techniczną.

[WPISZ CEL]

Wygeneruj plik markdown zawierający:

# Nazwa skilla

## Cel
Jednozdaniowe wyjaśnienie kiedy używać tego skilla.

## Kiedy używać
Lista sytuacji, w których agent powinien aktywować ten skill.

## Proces pracy
Sekwencja 5-8 kroków:
- analiza,
- planowanie,
- wykonanie,
- walidacja,
- review.

## Zasady
Lista ograniczeń i rzeczy, których agent nie powinien robić.

## Punkty kontrolne
Określ sytuacje, kiedy agent powinien zatrzymać się i poprosić o decyzję użytkownika.

## Kryteria zakończenia
Jak agent ma rozpoznać, że zadanie jest wykonane.

Zasady tworzenia:
- unikaj ogólników,
- nie opisuj teorii,
- dawaj konkretne działania,
- preferuj minimalny zakres zmian,
- uwzględniaj koszty czasu i kontekstu,
- projektuj dla dużego repozytorium,
- skill nie może zastępować AGENTS.md.
