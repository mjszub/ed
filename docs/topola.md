### 🛠️ Kompletna lista narzędzi do diagramów (Online + Offline)

#### 🟢 **Wersje Offline (Instalowane / Open Source)**
*Działają bez internetu. Idealne do pracy w trybie "deep work", ochrony danych i planowania w izolacji.*

| Narzędzie | Link / Pobierz | Krótki opis |
| :--- | :--- | :--- |
| **Draw.io (Desktop)** | https://github.com/jgraph/drawio-desktop | **Najlepszy wybór offline.** Oficjalna wersja desktopowa (Windows/Mac/Linux). Pełna funkcjonalność, brak limitów, eksport do lokalnych plików. |
| **Excalidraw (Desktop)** | https://github.com/excalidraw/excalidraw | Wersja offline (wymaga Node.js do uruchomienia lub użycia jako PWA w trybie offline). Styl "od ręki", wszystko lokalnie. |
| **yEd Graph Editor** | https://www.yworks.com/products/yed | **Potężne narzędzie do grafów.** Automatyczne układanie diagramów (algorytmy). Działa offline, działa na Windows/Mac/Linux. |
| **PlantUML (Standalone)** | https://plantuml.com/download | Narzędzie "diagram as code". Instalujesz lokalnie (Java), piszesz tekst, generujesz diagram. Całkowity brak internetu. |
| **Dia** | https://wiki.gnome.org/Apps/Dia | Klasyczne, lekkie narzędzie do diagramów (starszy styl). Bardzo proste, działa offline na Linux/Windows. |
| **LibreOffice Draw** | https://www.libreoffice.org | Część pakietu LibreOffice. Ogólna grafika, ale świetna do prostych schematów procesowych offline. |
| **Inkscape** | https://inkscape.org | Dedykowany edytor grafiki wektorowej (nie tylko diagramy). Pełna kontrola nad każdym pikselem, ale wymaga więcej pracy. |

#### 🔵 **Wersje Online (Przeglądarkowe)**
*Wymagają internetu (chyba że dodane jako PWA), ale są bardzo wygodne.*

| Narzędzie | Link | Krótki opis |
| :--- | :--- | :--- |
| **Excalidraw** | https://excalidraw.com | Najpopularniejszy styl "whiteboard". Szybki, darmowy, prosty. |
| **tldraw** | https://tldraw.com | Bardzo lekki, nowoczesny, świetny do szybkich szkiców i prototypów. |
| **Miro** | https://miro.com | Standard współpracy zespołowej. Nieskończona tablica. |
| **Eraser.io** | https://www.eraser.io | **Top dla deweloperów.** Automatyczne generowanie diagramów z kodu (Terraform, K8s). |
| **Whimsical** | https://whimsical.com | Najszybsze narzędzie do flowchartów i wireframe'ów. Bardzo intuicyjne. |
| **Lucidchart** | https://lucidchart.com | Profesjonalne, bogate w funkcje korporacyjne. |
| **Mermaid Live** | https://mermaid.live | Edytor online do diagramów "diagram as code" (dla GitHub/GitLab). |
| **Cloudcraft** | https://cloudcraft.co/ | Specjalistyczne 3D do architektury chmurowej (AWS/Azure). |

#### 💡 **Rekomendacja dla Samodzielnego Dewelopera**

1.  **Do ciężkiej pracy offline:** Pobierz **Draw.io Desktop**. To darmowy, potężny kombajn, który działa bez internetu i zapisuje pliki bezpośrednio na dysku.
2.  **Do szybkich szkiców offline:** Zainstaluj **yEd Graph Editor**. Jeśli masz skomplikowany graf, on sam go ładnie ułoży.
3.  **Do planowania z kodem:** Użyj **PlantUML** (zainstalowany lokalnie) lub **Mermaid** (w edytorze tekstu jak VS Code).
4.  **Do szybkiego podglądu online:** **Eraser.io** – pozwala wkleić fragment kodu i natychmiast zobaczyć diagram architektury.
